# Expense Tracker CLI (SyntexHub)

A powerful yet simple command-line based Expense Tracker developed using Python. 
This tool helps users efficiently record, manage, and analyze their daily expenses.

##  Features
* Add expenses with date, category, and amount
* View complete expense history
* Monthly expense summary
* Category-wise analysis
* Export data to CSV
* Visual charts using matplotlib

## Technologies Used
* Python
* CSV (File Handling)
* Matplotlib

## How to Run
pip install matplotlib
python expense_tracker.py

## Purpose
This project is built to practice Python fundamentals like file handling, functions, and data visualization through a real-world application.
